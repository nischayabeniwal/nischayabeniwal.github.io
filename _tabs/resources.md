# Cool Stuff & Useful Resources

A small collection of repositories, labs, tools, and learning resources that I’ve found genuinely useful while learning offensive security, web exploitation, malware analysis, and hardware hacking.

---

# Web Security & Bug Bounty

* [awesome-bug-bounty](https://github.com/djadmin/awesome-bug-bounty) <br>
  Massive collection of bug bounty resources, reports, tools, and methodologies.

* [KingOfBugBountyTips](https://github.com/KingOfBugbounty/KingOfBugBountyTips)<br>
  Practical bug bounty tips, tricks, payloads, and real-world findings.

* [PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings)<br>
  One of the best payload/reference repositories for web exploitation.

* [HackTricks](https://github.com/HackTricks-wiki/hacktricks)<br>
  Essential reference for pentesting, privilege escalation, Active Directory, cloud, and more.

* [Hacking-Cheatsheets](https://github.com/Ilias1988/Hacking-Cheatsheets)<br>
  Useful collection of penetration testing notes, commands, payloads, and methodologies.

---

# Labs & Practice Platforms

* [DVWA](https://github.com/digininja/DVWA)<br>
  Deliberately Vulnerable Web Application for learning web attacks safely.

* [OWASP Juice Shop](https://github.com/juice-shop/juice-shop)<br>
  Modern vulnerable application covering realistic web vulnerabilities.

* [WebGoat](https://github.com/WebGoat/WebGoat)<br>
  OWASP’s interactive insecure application for hands-on training.

* [PortSwigger Web Security Academy](https://portswigger.net/web-security)<br>
  Probably one of the best free resources for learning web exploitation.

* [Hack The Box](https://www.hackthebox.com/)<br>
  Labs and machines focused on realistic offensive security scenarios.

# Random Cool Tools

* [Impacket](https://github.com/fortra/impacket)<br>
  Essential toolkit for Active Directory and network protocol attacks.

* [GTFOBins](https://gtfobins.github.io/)<br>
  Unix binaries that can be abused for privilege escalation.

* [LOLBAS](https://lolbas-project.github.io/)<br>
  Living-off-the-land binaries for Windows exploitation and evasion.

* [Attiny85 BadUSB](https://github.com/MTK911/Attiny85)<br>
  DIY BadUSB projects using the ATtiny85 microcontroller.

* [FreeDomain](https://github.com/DigitalPlatDev/FreeDomain)<br>
  Free subdomain and dynamic DNS project useful for labs, testing, and self-hosted environments.
